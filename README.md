# Mohammed Ismail Portfolio

Build a professional, modern, high-performance full-stack developer portfolio website using React, Tailwind CSS, and lucide-react icons. The design should feature a sleek, minimalist aesthetic with smooth transitions, a fully working Dark/Light mode toggle, and a fully responsive layout optimized for mobile and desktop.

Include the following sections and precise content:

1. Navigation Bar (Navbar):

- Logo/Brand: "Mohammed Ismail" with a subtle glowing accent or neon dot.

- Links: About, Skills, Projects, Blog, Contact.

- Actions: A smooth Dark/Light mode toggle button and a "Download Resume" CTA button.

2. Hero Section:

- Badge: "🚀 IT Undergraduate & Full Stack Developer"

- Headline: "Building intelligent web apps, AI tools, and seamless user experiences."

- Subheadline: "Information Technology student at C. Abdul Hakeem College of Engineering & Technology, passionate about modern web stacks, full-stack engineering, and AI-driven applications."

- Call-to-Action Buttons: "Explore Projects" (primary) and "Get in Touch" (secondary).

- Visuals: A modern developer-themed card layout or clean abstract tech graphic placeholder.

3. About & Interactive Resume Section:

- Bio: Highlight a journey through full-stack web development, prompt engineering internships, and embedded systems/IoT prototyping.

- Education Details: B.Tech Information Technology at C. Abdul Hakeem College of Engineering & Technology (Anna University Regulation 2025).

- Experience Highlights: 

  * Full Stack Web Development Intern at Thiranex.

  * Prompt Engineering Intern at Future Interns (Built AI copy generators, UGC ad script tools, SEO clusters).

  * Android Development tasks (CodeAlpha / CodSoft).

- Skills Category Tabs/Grid with icons:

  * Frontend: React, Next.js, TypeScript, JavaScript, Tailwind CSS, HTML5, Bootstrap.

  * Backend & Databases: Python (FastAPI), Node.js, MongoDB, MySQL.

  * Mobile & IoT: Kotlin, Java, Jetpack Compose, ESP32, Arduino IDE.

  * Tools & Cloud: Git, GitHub, Vercel, Netlify, Render, Postman.

4. Projects Section (with Filter Tabs: All, Full Stack, AI & Tools, Mobile & IoT):

Include cards for these real projects with title, description, tech stack tags, live demo links, and GitHub links:

- LogicGuard: A web application evaluating propositional logic constraints using FastAPI and React (Anna University Discrete Mathematics course project).

- NeonSnap Studio: A web-based AR photo booth with live face tracking, custom overlays, and QR code generation.

- AI Content Suite (Future Interns): AI website copy generator, UGC ad script generator, and SEO content cluster engine.

- Fitness Tracker & Flashcard Apps: Jetpack Compose mobile applications built during internship tasks.

5. Dynamic Blog / Insights Section:

- Card layout displaying technical articles and internship journey logs (e.g., "My Experience as a Prompt Engineering Intern at Future Interns", "Building LogicGuard: Connecting React to FastAPI").

6. Interactive Contact Section:

- Form fields: Name, Email, Subject, and Message.

- Interactive validation states, loading spinner on submit, and a success/error notification toast message when simulated or submitted.

- Direct contact details: Email and LinkedIn profile links.

7. Footer:

- Copyright notice © 2026 Mohammed Ismail H.

- Social media links with icons: GitHub, LinkedIn, Email.
